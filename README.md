# 🐼 The Daily Craves - Food Cart Official Website

Website for **The Daily Craves** street food & cafe express cart, featuring authentic panda mascot branding, exact menu pricing, portions, shopping cart, and WhatsApp order generator.

## 🚀 Quick Launch
- **Double click `open-website.bat`** or double click `index.html` to view the website directly in any web browser (Chrome, Edge, Firefox, Brave, Safari).

---

## 🌟 Features Included

1. **Brand Identity**:
   - Cute Panda chef mascot & cafe theme.
   - Taglines: *"Good Food. Good Mood. Every Day!"* & *"Served with love & spicy happiness ❤️"*.
   - Instagram spotlight with *"Snap It, Share It, Tag Us!"* and official QR code.

2. **Complete 100% Exact Menu**:
   - **Momos**: Veg, Paneer, and Chicken options across Steamed, Fried, Kurkure, and Creamy styles (Half / Full).
   - **Snacks**: Regular French Fries, Peri Peri Fries, Spring Rolls, Chicken Nuggets (Half / Full).
   - **Cold Coffee**: Classic, Premium (with choco chip & ice cream), Chocolate, Hazelnut, Vanilla, Caramel, Irish Cream, Kit Kat, Oreo (Small / Medium / Large).
   - **Milk Shakes**: Vanilla, Strawberry, Black Currant, Hazelnut, Rasmalai, Butterscotch, Chocolate, Kit Kat, Oreo (Medium / Large).
   - **Mojitos**: 14 flavours (Virgin, Blood Orange, Blueberry, Green Apple, Blue Lagoon, Kala Khatta, Merry Berry, Cranberry, Strawberry, Tropical Fruit Beer, Bubblegum, Lavender, Pineapple, Watermelon) (Medium / Large).

3. **Ordering System**:
   - **Contact / WhatsApp Number**: `8795412956`
   - **Direct Call Link**: One-tap phone calling (`tel:8795412956`).
   - **WhatsApp Cart Checkout**: Formats items, sizes, quantities, totals, delivery address, and opens direct WhatsApp chat.
   - **Delivery Rules**: Minimum order ₹350 with live progress meter.

4. **Filters & Search**:
   - Real-time search by food name or keywords.
   - Veg / Non-Veg diet toggles.
   - Category navigation tabs.

5. **Responsive & Mobile-Ready**:
   - Mobile bottom bar with floating cart summary.
   - Touch-friendly portion buttons.
   - Fast loading with zero heavy frameworks.

## 🌐 How to Host Online (Free)
1. **GitHub Pages**: Upload this folder to a GitHub repository and turn on GitHub Pages in Settings.
2. **Netlify / Vercel**: Drag and drop the `the-daily-craves` folder to [Netlify Drop](https://app.netlify.com/drop) to get a free live URL (e.g. `thedailycraves.netlify.app`).
